# DESCRIÇÃO DETALHADA DE TODO O PROJETO

O Projeto final desta disciplina consiste em escrever um sistema completo para resolver algum problema. O grupo escolhe qual problema irá implementar.

A implementação deve ser feita 100% em python orientado à objetos e deverá ter, necessariamente, os seguintes requisitos:

- Pelo menos 5 classes
- Pelo menos 1 caso de:
- Herança
- Polimorfismo
- Associação
- Método privado
- Atributo privado
- Programa principal deve criar pelo menos dois objetos
- Tudo no sistema deve ser implementado. O grupo pode usar bibliotecas gráficas para melhorar o visual.
